# شجرة العائلة

| الصفحة | الملف |
|---|---|
| النسب (الشجرة) | `index.html` |
| الفعاليات (التقويم) | `events.html` |
| الذكريات (الصور) | `memories.html` |
| لوحة التحكم | `admin.html` + `admin.js` |
| البطولات والتسجيل فيها | `tournaments.html` و `tournaments.html?t=…` (تُدار من قسم «البطولات» في لوحة التحكم) |
| صفحة الدعوة وتأكيد الحضور | `invite.html?i=…` (الرد يمر عبر دالة Supabase `invite-respond`) |
| ملف التقويم والاشتراك | `api/ics.js` → `/api/ics?id=…` و `/api/ics` |

- الشكل المشترك للصفحات الجديدة: `site.css` و `common.js`
- الهيدر وبنر الآيات المتحرك والفوتر وشريط الجوال السفلي (مشتركة بين الصفحات العامة): `layout.css` و `layout.js`
- الاتصال بقاعدة البيانات: `config.js` (مفتاح عام آمن للمتصفح، والصلاحيات تفرضها قاعدة البيانات)
- جداول البطولات ودوالها في قاعدة البيانات: `supabase/migrations/20261119_tournaments.sql`
